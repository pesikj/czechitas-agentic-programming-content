# czechitas-agentic-programming-content

Course materials for the Czechitas Course Terminal website
([`czechitas-agentic-programming`](../czechitas-agentic-programming)).

Lecture 00 contains a draft installation guide for Windows and macOS. The placeholder
lectures 01–03 have been removed; the remaining course materials are yet to be created.

- Format: see `docs/content-contract.md` in the website repository.
- Validate before pushing (from the website repository):

  ```bash
  npm run content:validate -- ../czechitas-agentic-programming-content
  ```

Changes become visible to learners only after an administrator runs **Aktualizovat obsah**.
