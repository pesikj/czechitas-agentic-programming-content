# Course context

Before creating or revising course materials, read [knowledgebase/course-memory.md](knowledgebase/course-memory.md) for the audience, prerequisites, organizational constraints, and teaching goals.

Keep confirmed decisions separate from proposals and unresolved details. When the organizer changes a course decision, update the memory accordingly. The source transcript is linked in the memory for reference.

# Own projects

Attendees work on their own project during the lectures, not only on the shared examples (confirmed by the organizer on 2026-10-22). When creating or revising a lecture:

- Dedicate part of the exercises to the attendee's own project: after the shared example teaches a concept, an exercise applies it to their own app.
- Keep these exercises open enough to fit different project ideas, but give a concrete result the attendee can check, plus a prompt template they adapt.
- Build on what the attendee already did for their project in earlier lectures (for example `produkt.md` and the approved brainstorming design from lecture 05) instead of starting over.
