# Git

Minule jsi nechal(a) agenta napsat program s nákupem, naučil(a) ses číst jeho chyby a přidal(a) do něj balíček a logy. Log ti řekne, co program dělal. Dnes se naučíš hlídat druhou stranu: co se změnilo v kódu.

1. **Git** – co je systém pro správu verzí, repozitář a proč ho používat.
2. **Git ve VS Code** – jak v projektu zapnout Git, udělat commit, prohlédnout si změny a historii a zahodit nepovedenou úpravu.
3. **GitHub** – jak projekt publikovat na internet jako soukromý nebo veřejný repozitář.
4. **Větev, pull request a merge** – jak novou funkci vyzkoušet ve větvi, zkontrolovat ji v code review a sloučit do hlavní verze.
5. **Git a AI agent** – proč udělat commit dřív, než necháš agenta měnit kód, a jak zkontrolovat, co změnil.

**Proč to potřebuješ:** Agent umí během minuty změnit několik souborů najednou. Když se úprava nepovede, potřebuješ vidět, co přesně změnil, a vrátit se k verzi, která fungovala. Bez Gitu máš jen popis od agenta a naději, že je přesný. Od příští lekce budeš s agentem stavět větší aplikaci po krocích a každý krok uložíš právě commitem.

**Po lekci budeš umět:**
- Víš, co je Git, repozitář a commit a proč si uložit funkční verzi dřív, než necháš agenta měnit kód.
- Umíš ve VS Code zapnout Git, udělat commit a v panelu Source Control zkontrolovat, které řádky agent změnil.
- Umíš publikovat projekt na GitHub a víš, kdy zvolit soukromý a kdy veřejný repozitář.
- Umíš připravit novou funkci ve větvi a dostat ji přes pull request a code review do `main`.
