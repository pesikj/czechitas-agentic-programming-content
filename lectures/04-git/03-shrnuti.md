# Shrnutí

- Víš, co je Git, repozitář a commit, a víš, že před každou prací agenta si máš uložit funkční verzi commitem.
- Umíš ve VS Code zapnout v projektu Git, nastavit jméno a e-mail, udělat commit a v panelu Source Control zkontrolovat, které řádky agent změnil. Znáš i odpovídající příkazy (`git status`, `git diff`, `git commit`, `git log`).
- Umíš publikovat projekt z VS Code na GitHub jako soukromý nebo veřejný repozitář a víš, že do repozitáře nepatří hesla ani osobní údaje.
- Umíš novou funkci připravit ve větvi, projít ji v pull requestu (code review), sloučit do `main` a stáhnout si ji příkazem pull.
