# Shrnutí

- Víš, co je log a k čemu slouží úrovně DEBUG, INFO, WARNING, ERROR a CRITICAL, a víš, že do logu nepatří hesla ani jiné citlivé údaje.
- Umíš nechat agenta přidat do programu logování a z logu zjistit, co se stalo, u které položky a kdy. Poznáš i tichou chybu, kterou log nezachytí.
- Umíš nechat AI shrnout log a její závěr ověřit v datech a kódu.
- Umíš ve VS Code zapnout v projektu Git, nastavit jméno a e-mail, udělat commit funkční verze dřív, než necháš agenta měnit kód, a v panelu Source Control zkontrolovat, které řádky agent změnil.
- Umíš publikovat projekt z VS Code na GitHub jako soukromý nebo veřejný repozitář, novou funkci připravit ve větvi, projít ji v pull requestu (code review), sloučit do `main` a stáhnout si ji příkazem pull.
