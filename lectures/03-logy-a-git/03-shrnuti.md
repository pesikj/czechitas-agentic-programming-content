# Shrnutí

- Víš, že log je záznam, který program zapisuje během práce, a že každý řádek má čas, úroveň a zprávu.
- Znáš úrovně logů DEBUG, INFO, WARNING, ERROR a CRITICAL a víš, že slouží jako filtr.
- Umíš nechat agenta přidat do programu logování do souboru a zkontrolovat, že výjimka chybu zapíše, místo aby ji spolkla.
- Umíš z logu zjistit, co se stalo, u které položky a kdy.
- Víš, že do logů nepatří hesla, čísla karet ani jiné citlivé údaje.
- Víš, že logy se dají monitorovat, a umíš nechat AI log shrnout a její závěr ověřit v datech a kódu.
- Umíš poznat tichou chybu, kterou nezachytí ani výjimka, ani log, a nechat agenta program upravit tak, aby se o ní dozvěděl(a).
- Víš, že Git je systém pro správu verzí a že repozitář je složka projektu, jejíž historii Git sleduje.
- Víš, že commit je pojmenovaný snímek projektu, a umíš vysvětlit, proč ho udělat před každou prací agenta.
- Víš, co ukážou `git status`, `git diff` a `git log`, a že `git diff` je nejrychlejší způsob, jak zkontrolovat, co agent změnil.
- Víš, co dělají `git push`, `git pull` a `git clone` a čím se liší GitHub, GitLab a Bitbucket.
- Víš, k čemu slouží větev, pull request a merge.
