# Python v době AI

Minule sis nainstaloval(a) uv, Python, VS Code, Git a AI agenta. Dnes je poprvé použiješ: zjistíš, jak agent pracuje s tvým počítačem, co to vlastně znamená *programovat* a jak agenta nastavit. Projdeme pět témat, která na sebe navazují:

1. **Terminál** – textové rozhraní, přes které agent (i ty) ovládá počítač, a projekt ve VS Code, ve kterém budeš pracovat.
2. **Programová logika** – jak rozložit úkol na přesné kroky, kterým rozumí počítač.
3. **Programovací jazyky** – v čem se tyhle kroky zapisují a co potřebuješ k jejich spuštění.
4. **AI, vibe coding a agentní programování** – jak dnes kód píše AI a proč je pořád důležité, abys mu rozuměl(a) ty.
5. **Nastavení agenta** – co smí agent udělat bez ptaní, jaký model a jak dlouhé přemýšlení zvolit a jak hlídat limity předplatného.

**Proč to potřebuješ:** Agent ti napíše kód za pár vteřin, ale sám nepozná, jestli dělá to, co jsi chtěl(a). V lekci uvidíš program na sčítání nákupu, který bez jediné chybové hlášky sečte koruny s eury a vypíše nesmysl. Takovou chybu odhalíš jen tehdy, když rozumíš tomu, co agent v terminálu dělá, a umíš si postup programu rozmyslet sám(a). A protože agent sahá na soubory v tvém počítači, musíš vědět, co mu dovolíš. Na těchhle základech stojí celý kurz – použiješ je pokaždé, když budeš s agentem stavět vlastní aplikaci.

**Po lekci budeš umět:**
- Umíš se pohybovat v terminálu (`pwd`, `cd`, `ls`) a zkontrolovat, jaké příkazy spustil agent.
- Umíš rozložit úkol na přesné kroky, zapsat je jako pseudokód a ověřit je v trasovací tabulce.
- Víš, čím se liší Python, JavaScript, TypeScript a Rust, a co potřebuješ ke spuštění kódu.
- Víš, čím se liší AI v chatu, vibe coding a agentní programování, a umíš si od agenta nechat nejdřív navrhnout plán.
- Umíš agentovi nastavit režim oprávnění, model a úroveň přemýšlení a zkontrolovat, kolik ti zbývá z limitů.
